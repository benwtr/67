# 6 7

A tiny Space-Invaders tribute, dedicated to Ruby — you play a "6" shooting down
waves of "7"-shaped aliens. Watch for the occasional "9" drifting across the
top of the screen... because sometimes seven eats nine.

**[▶ Play it](https://benwtr.github.io/67/)**

## Run it

No build step needed. Either:

- Open `index.html` directly in a browser, or
- Serve it locally: `python3 -m http.server` then visit `http://localhost:8000`

## Controls

Desktop:

- **Arrow keys / A-D** — move
- **Space** — shoot
- **Enter** — start / restart

Mobile:

- **Tap** — start / restart
- **Drag** — the 6 follows your finger, and auto-fires while you hold
